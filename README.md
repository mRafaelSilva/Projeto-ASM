# Projeto-ASM

#### Para iniciar:

1. Cria um python venv e corre o comand - `source ${nome_do_venv}/bin/activate`;
2. Instala as dependencias com - `pip install -r requirements.txt`;
3. Corre `sh run.sh` para correr o openfire no docker e iniciar os agentes;
4. Abrir `localhost:9090` para configurar o openfire (caso seja a primeira vez a correr o docker);

Se houver algum problema a iniciar, provavelmente terá haver com falta de configuração no OpenFire.
